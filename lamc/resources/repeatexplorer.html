RepeatExplorer includes utilities for Graph-based clustering and characterization of repetitive sequences in next-generation sequencing data and tools for the detection of transposable element protein coding domains.

Source code for the original version of RepeatExplorer server can be downloaded from Bitbucket. Basic RepeatExplorer documentation and installation instruction can be found in user manual

RepeatExplorer can be used through Galaxy based web interface on our public server www.repeatexplorer.org. Alternative public server can be accessed at address https://galaxy-elixir.cerit-sc.cz. This alternative server is provided in the test mode within Elixir CZ project and is maintained by CESNET and CERIT-SC that are participants of this project.

SeqGrapher

SeqGrapheR is a program for vizualization in exploration of sequence based graphs generated in RepeatExplorer output. SeqGrapheR program is now deposited in github repository. See also our SeqGrapheR manual and input data examples.
