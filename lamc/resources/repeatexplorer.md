RepeatExplorer includes utilities for [**Graph-based clustering and characterization of repetitive sequences in next-generation sequencing data**](http://www.biomedcentral.com/1471-2105/11/378) and tools for the detection of transposable element protein coding domains.

Source code for the original version of RepeatExplorer server can be downloaded from [Bitbucket](https://bitbucket.org/repeatexplorer/repeatexplorer). Basic RepeatExplorer documentation and installation instruction can be found in user manual <span class="unavailable">(temporarily unavailable)</span>.

RepeatExplorer can be used through Galaxy based web interface on our public server [www.repeatexplorer.org](http://www.repeatexplorer.org/). Alternative public server can be accessed at address [https://galaxy-elixir.cerit-sc.cz](https://galaxy-elixir.cerit-sc.cz). This alternative server is provided in the test mode within [Elixir CZ project](https://www.elixir-czech.cz/) and is maintained by [CESNET](https://www.cesnet.cz/) and [CERIT-SC](https://www.cerit-sc.cz/en/index.html) that are participants of this project.

## SeqGrapheR

SeqGrapheR is a program for visualization in exploration of sequence based graphs generated in RepeatExplorer output. SeqGrapheR program is now deposited in [github repository](https://github.com/kavonrtep/SeqGrapheR). See also our SeqGrapheR [manual]({{ '/lamc/resources/manual.pdf' | relative_url }}) and [input data examples]({{ '/lamc/resources/Example_Data.zip' | relative_url }}).
